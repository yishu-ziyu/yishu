## 方向

对齐「三仓库融合」意图：Clicky 的菜单栏语音外壳 + nuphus 的通用电脑操控 + grok-bot 的推理路由、MCP、例程与对话界面，全部 Mac 原生外观。价值函数定为像《Her》。决定与推翻的旧条目见 `runtime/tasks/20260904-fusion-intent.md`。

## 判断

- 不重做。外壳、协议、真机权限、评测骨架已在真 Mac 跑通；缺的三块有接缝。
- 架构：碰 Mac 的 Swift；推理、工具、记忆、例程留 TS runtime。grok-bot 控制平面搬进 runtime，交互层用 SwiftUI 重做。
- 通用操控放开，验证分层，安全门「预告即执行」。
- Claude Code 走本机 CLI headless + 奕枢 MCP 服务端 + `--permission-prompt-tool`，不读 token。
- EverOS 用足（情节、技能、反思），而不是拆掉；`记忆.md` 必须回到唯一真相。
- 里程碑：M0 像人 → M1 手 → M2 对话窗 → M3 脑 → M4 记忆 → M5 帮手。A–J 十处相冲全修。
