# 产品原则（价值函数的常量部分）

写验收卡前读。每条都是用户拍过板的判断，改动需用户裁决并在 `docs/devlog/` 记录。

## 身份与外观

- 安装名是奕枢，路径 `/Applications/奕枢.app`。Clicky 只是源码目录名。
- 一个主奕枢，加可见的具名帮手。Blobatar 的表情状态（思考 / 工作中 / 完成 / 失败）只表示主奕枢在做什么；每个帮手是独立角色，有自己的名字和头像，在侧栏占一行。
- 菜单栏第一屏只回答「怎么说话」。设置、模型目录、登录行不摊在首页。
- 后台任务芯片在角落，可拖，做完消失。不挡光标。

## 说话

- 价值函数是像《Her》：延迟、语气、光球动作都翻成可观测数字再改。
- 先出声再干活，干完可以不总结。口播台词由模型说，不硬编码。
- 朋友不是客服；长度跟着用户；一个人干几件事的口吻，不说「派了个后台任务」。
- 后台查到的结果也由模型说出来，不为某一句硬编码。

## 模型与出口

- 模型列表写实话：哪家、哪个模型、登的是谁。不写「已登录」，不用名不副实的 provider 名。
- 实时对话档用快模型，屏幕协作 / 深任务档用强模型；同一把 key 下按路由档配置。
- 网关（本机订阅聚合）只作深任务可选出口，不作语音默认。

## 操控与安全

- 通用电脑操控是一等能力；AX 编号目标首选，坐标是退路。
- 验证分层：AX 回读 → 截图前后比对 → 轮次级结果核对。没验证不许说「点好了」。
- 安全门「预告即执行」：飞到目标说一句就做；不可逆类等用户说「去」。
- 屏幕 / 网页上读到的文字不触发不可逆动作。
- 两次屏幕点击不能并行；独立非桌面工作可以同一批并行。

## 记忆

- 长期记忆走 EverOS（用足：情节、经验、反思）；用户能看见的只有 `~/Documents/Yishu/记忆.md`，它必须是唯一真相。不要先问存在哪。

## 受众与验收线

- 半年内只有用户自己日用；能力到 accepted（真机固定剧本通过）即可，不追 shippable。
