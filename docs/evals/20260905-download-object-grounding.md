## 一句话任务

用户口述下载文件时，先从本机 Downloads 取得真实候选，将唯一匹配文件与上传区绑定，确认后拖放。

## Change（用户能观察到什么）

同音字、口述“点 txt”或省略扩展名不再要求用户精确拼写；唯一匹配时显示真实文件名并请求一次确认。多候选会说明歧义，读取失败只按本机观察报告，不从 workspace 授权推断 Downloads 权限。

## Not this（不算数的替代）

- 硬编码测试文件别名或把听写文本强行改成固定文件名。
- 模型凭空造路径，或只做字符串纠错而不检查实际文件。
- 用模拟拖放通过冒充正式 App 页面出现附件。

## Goal / Hard bar / Improve

- Goal：真实目录匹配 → ContextFrame 携带有时间的文件观察 → runtime 仅绑定唯一真实候选与唯一上传目标，建立无工具预览 → 确认后原执行器拖放。
- Hard bar：目录不相关时零枚举；只读顶层普通可读文件，不读内容；多个同音候选不自动选；确认前零拖放；候选过期/失败/被截断不能授予文件权限；无匹配不说缺权限。
- Improve：同音与口述扩展名失败用例通过，测试夹具改名后同样有效。
