## 一句话任务

把 runtime 里已经存在但看不见的子会话变成侧栏里的具名帮手：随时派、随时删、做完第一人称汇报；帮手之间和主奕枢能在一个群组里轮流说；帮手可以借用桌面操控但同一时刻只有一个执行者。

## Change（用户能观察到什么）

说「派个帮手去把这份 PDF 的要点整理出来」，对话窗左侧多一行「整理员」带头像和「工作中」状态；做完它在对话流里说「整理好了，三个要点是…」；说「把整理员撤了」那行消失。建一个群组把主奕枢和两个帮手放进去，问一个问题，它们轮流答，@谁谁答，没话说的可以跳过。帮手要点屏幕时，主奕枢让出桌面，等它做完。

## Not this

- 帮手是另一套后台任务系统而不是 `DelegationCoordinator` 的子会话。
- 帮手汇报说「后台任务已完成」这类系统腔。
- 两个帮手同时点屏幕。
- 云端 agent 或跨用户房间。

## Goal / Hard bar / Improve

- Goal：一个真实任务由用户派给帮手，从侧栏出现到汇报到删除全程可见。
- Hard bar：任何一次两执行者并发点屏幕 = 失败；帮手结果丢失或送两次 = 失败。
- Improve：帮手从派出到第一句进展播报的时间（目标 ≤10 s）。

## 验收标准

| # | 标准 | evaluator | 证据 |
|---|---|---|---|
| 1 | 帮手 = `DelegationCoordinator` 子会话 + kernel 持久化的身份（名字、头像种子、性格一句话、创建时间） | 机器：kernel store 单测；重启后帮手仍在 | 测试输出 |
| 2 | 创建：语音「派个帮手去…」或 UI 按钮；名字由模型按任务起（可改） | 机器：协议 `helper.created` 事件；人评：名字是否顺口 | 日志 + 人评 |
| 3 | 侧栏行：头像、名字、状态（空闲 / 工作中 / 需要你 / 完成 / 失败），点开看它的对话流 | 机器：Swift 单测（状态映射）；人评 | 测试 + 截图 |
| 4 | 删除：语音或 UI 删除 → 子会话释放、行消失、历史归档可查 | 机器：`releaseConversationSession` 被调；单测 | 测试输出 |
| 5 | 汇报第一人称，进主对话流，由模型说；无「后台任务已开始 / 完成」 | 机器：`rg` 提示词与芯片文案；人评 | rg + 人评 |
| 6 | 结果送达恰好一次（Result Inbox claim / ack 沿用），runtime 重启后仍恰好一次 | 机器：kill runtime 中途 → 结果 1 条 | 日志 |
| 7 | 桌面锁可借：帮手申请桌面 → 主奕枢让出并说一句 → 帮手做完归还；同一时刻只有一个执行者 | 机器：`resource-lease.ts` 单测（借出 / 归还 / 超时收回） | 测试输出 |
| 8 | 群组：主奕枢 + N 帮手一个房间；轮流发言；`@名字` 指定；成员可「跳过」 | 机器：脚本化三方对话 5 轮，顺序与 @ 规则正确 | 测试输出 |
| 9 | 帮手的工具权限 = 主奕枢的子集（默认无桌面操控，借锁才有；无递归派帮手） | 机器：`session-policy.ts` 单测 | 测试输出 |
| 10 | Blobatar 表情只表示主奕枢状态；帮手状态用自己的头像与状态标签 | 人评：录屏 | 录屏 |
| 11 | 真机：一个真实任务派、看、删全程 | 人评 | 录屏 |
| 12 | 全部检查绿 | 机器：门禁命令 | 输出 |

## 非目标

- 帮手之间私聊。
- 帮手用不同模型 / 供应商（先同一套路由）。
- 云端执行。
