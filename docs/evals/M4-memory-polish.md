## 一句话任务

`记忆.md` 成为唯一真相且会演化：普通对话的新事实进去，纠正让旧事实作废，能回答「上周我们聊过什么」，奕枢记得自己怎么做成过事；能接外部 MCP 工具；对话流有表情回应、选择卡、图片、线程、搜索。

## Change（用户能观察到什么）

你说「我最近改喝咖啡了」，打开 `~/Documents/Yishu/记忆.md` 看到绿茶那条被标作废、咖啡那条新增；你直接改文件，30 秒后它的回答体现；问「上周三我们聊了什么」它给带日期的三句话；它做成过一次「整理截图」后，下次说「像上次那样」它知道；设置里加一个 MCP 服务器后模型多了那些工具；对话里能对消息点表情、它提问用可点的选项卡、拖图片进去、回复某条、搜历史。

## Not this

- 换掉 EverOS 却不迁移已有记忆。
- 两份记忆并存（EverOS 的 Markdown 与 `记忆.md` 内容不一致）。
- 纠正只是追加一条「不喝绿茶了」而旧条仍被召回。
- 先上向量检索再谈平索引。
- 召回预算退化到 >300 ms。

## Goal / Hard bar / Improve

- Goal：一周日用后，`记忆.md` 里没有一条过期事实被召回；「上周聊过什么」三问三准。
- Hard bar：任何一轮召回超 300 ms 预算仍阻塞模型请求 = 失败；`记忆.md` 与系统真用的记忆不一致 = 失败。
- Improve：召回命中率（用户判「这条相关」的比例）。

## 验收标准

### 记忆

| # | 标准 | evaluator | 证据 |
|---|---|---|---|
| 1 | `记忆.md` 与 EverOS 的用户 profile 是同一份文件（symlink 或 root 配置），改任一处另一处即变 | 机器：写文件 → 30 s 内 EverOS `search` 返回新内容；反向亦然 | 脚本输出 |
| 2 | EverOS 开着时普通对话的新事实也进 `记忆.md`（不再只进 EverOS 内部 Markdown） | 机器：说 3 条事实 → 60 s 内文件含 3 条 | 文件 diff |
| 3 | 纠正即作废：「我不喝绿茶了」→ 旧条目标作废（不删，标记）并从召回排除；`supersedes` 真的被写 | 机器：脚本化 5 组纠正 → 召回 0 次返回旧事实 | 测试输出 |
| 4 | 跨会话情节：「上周三我们聊了什么」→ EverOS episode 检索 → 带日期的回答 | 机器：种入 3 个会话 → 3 问 3 准 | 测试输出 |
| 5 | 奕枢经验：已验证成功的任务进 EverOS cases；下次同类任务提示词里带「上次怎么做的」 | 机器：日志 `recall.done` 含 case 条目 | 日志 |
| 6 | 反思：空闲时跑一次 EverOS OME，合并碎片情节、更新画像；有运行日志 | 机器：触发一次 → 画像文件变更 diff | diff |
| 7 | 召回预算 ≤300 ms 保持；EverOS 不健康时只用 `记忆.md` 且轮次不等 | 机器：`check-latency.mjs --metric recall` p95 ≤300；停 EverOS 后说 5 轮首字不变 | 脚本输出 |
| 8 | 确定性问题走本地 SQL 工具 `query_history`：「上次聊 X 是什么时候」「今天我在 Xcode 多久」 | 机器：10 问精确答案对照 SQLite | 测试输出 |
| 9 | 用户删除 / 编辑 `记忆.md` 后 EverOS 同步（删除不再是「只压制召回」） | 机器：删一条 → EverOS `search` 不再返回 | 脚本输出 |
| 10 | 私密会话范围不写任何记忆（沿用） | 机器：单测 | 测试输出 |
